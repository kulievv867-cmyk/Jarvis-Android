# Jarvis-Android

Персональный голосовой ассистент для Android в духе J.A.R.V.I.S. — оффлайн распознавание речи, нейросеть для свободных вопросов, встроенный музыкальный плеер с потоковой загрузкой и системные команды.

## Возможности

- **Wake-word + barge-in.** Слово «Джарвис» активирует слушание; новой командой можно прервать ответ Джарвиса на лету.
- **Оффлайн распознавание речи (Vosk)** — мини-модель ~88 МБ встроена в APK, работает без интернета.
  - Расширенный словарь алиасов имени, fuzzy-match (edit distance ≤ 1), DSP-цепочка с NoiseSuppressor / AGC / AcousticEchoCanceler.
- **Парсер русских числительных** (`семь тридцать утра`, `полседьмого`, `без четверти восемь`, `четверть девятого`) для будильников/таймеров/напоминаний.
- **Команды:**
  - Открыть/закрыть приложение (`открой телеграм`, `закрой ютуб`).
  - Переводчик (`переведи на английский «привет, как дела»`).
  - Будильник в **системные «Часы»** (`AlarmClock.ACTION_SET_ALARM`) + локальный fallback.
  - Таймер в системные часы + локальный fallback.
  - Напоминания.
  - Воспроизведение музыки **внутри приложения** через NewPipeExtractor → ExoPlayer (без открытия Spotify/YT).
  - Стоп-музыки голосом с агрессивным early-stop по partial-результату Vosk.
  - Mute / Shutdown.
- **LLM-фолбэк** (OpenAI / OpenRouter) для свободных вопросов с персональным контекстом (имя, город, страна, часовой пояс, текущее время).
- **Погода** скрапится с `yandex.ru/pogoda/<город>` и подставляется в системный промпт LLM.
- **Edge TTS** для голоса Джарвиса с DSP-модулятором (Stark-эффект).
- **Текстовый ввод** — поле «Напишите Джарвису» под лентой транскрипта; команды без обязательного wake-word.
- **5 цветовых тем** (Голубая, Оранжевая, Зелёная, Графит, Светлая) с переключаемой иконкой приложения через activity-alias.

## Сборка

```bash
# Установите Android SDK 34 и подсуньте путь
echo "sdk.dir=/path/to/android-sdk" > local.properties

# Опционально: ключ OpenAI / OpenRouter в окружение для встроенного дефолта
export OPENAI_API_KEY="sk-or-v1-..."

# Соберите debug APK
./gradlew assembleDebug

# APK будет здесь:
ls app/build/outputs/apk/debug/app-debug.apk
```

Без `OPENAI_API_KEY` ассистент использует только локальные команды; ключ можно ввести в Настройках приложения после установки.

## Архитектура (кратко)

- `core/JarvisService` — Foreground-сервис, слушает микрофон постоянно, обрабатывает wake-word, запускает Brain.
- `core/Brain` — парсит команду через `core/Intents`, вызывает соответствующий модуль (`commands/*`) или LLM-фолбэк (`llm/OpenAiClient`).
- `core/Speaker` + `voice/EdgeTts` — синтез речи + DSP-модулятор.
- `core/MicListener` + Vosk — wake-word + STT.
- `commands/MusicService` — ExoPlayer-плеер с уведомлением.
- `music/MusicSearch` (NewPipeExtractor) + `music/PipedSearch` (Piped public API fallback).
- `ui/MainActivity` + `ui/SettingsActivity` + `ui/ThemeManager` — интерфейс и темы.
